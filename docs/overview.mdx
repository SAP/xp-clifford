# Import existing resources

Teams rarely start on a new green field when developing cloud landscapes. 
Many teams wonder **how Crossplane Providers work with "existing cloud landscapes"**. 

![Overview](/img/import-cli.png)

This page outlines recommended user-journeys when introducing Crossplane Providers to existing cloud landscapes and links the respective end-user guides.

For commonly used Crossplane providers, we created a CLI that allows you to import most of its ressources.

Check out the following links to learn more.
