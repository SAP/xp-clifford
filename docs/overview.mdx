# Overview

When introducing Crossplane, just like any technology, we almost never start on a green field.

Most setups bring already-existing ressources *(Applications, services, infrastrure etc.)*.

![Overview](/img/import-cli.png)

Crossplane supports [importing existing ressources](https://docs.crossplane.io/latest/guides/import-existing-resources/) - however, this only partly solves the task of turing existing ressources into reusable YAML ressources.

With [xp-clifford](#underlying-framework), we created a framework that any Crossplane provider can pick up.

It brings **CLI import capabilities to any Crossplane provider** allowing users to **generate YAML ressources for their existing ressources**.

Read our [end-user guide](/docs/xp-clifford/docs/end-user-guides/exporter-install) to learn how to use the framework. The [contribution guide](/docs/xp-clifford/docs/contribution-notes/getting-started) walks you through the steps required when bringing this methodology to any Crossplane provider.
